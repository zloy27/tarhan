# Заполнение сезонов и каскад — 26 октября 2026

По прямому поручению пользователя заполнены и опубликованы в Local существовавшие черновики 2022–2023 (495), 2023–2024 (496), 2024–2025 (497). Сезон 2021–2022 не изменён. Это страницы архива, настройки сезонов участия не менялись.

Источники: https://www.tarhan-history.ru/2022_2023/, https://www.tarhan-history.ru/2023_2024/, https://www.tarhan-history.ru/2024_2025/. Прямой HTTPS-запрос обнаружил просроченный сертификат; публичный HTML и фотографии загружены отдельными запросами с отключённой проверкой сертификата, без учётных данных. Это не изменение настроек сайта или браузера.

Данные: `wordpress/wp-content/themes/tarhan/content/season-2022-2023.json`, `season-2023-2024.json`, `season-2024-2025.json`. Каждый файл содержит источник и SHA256 полученного HTML. Тексты распределены по существующим полям без повторения финалистов в результатах. Фотографии хранятся в `src/assets/photo/seasons/<период>/` и импортированы в медиатеку Local. Обложка — первая доступная фотография своего сезона. Даты финалов в исходных страницах не указаны, поле оставлено пустым.

Галереи: 13, 14 и 16 фотографий соответственно. Повторяющиеся URL фотографий и публикаций исключены. На источнике HTTP 404:

- `/static/pages/img/tarhan/2022_2023_photos/9.jpg`
- `/static/pages/img/tarhan/2022_2023_photos/11.jpg`
- `/static/pages/img/tarhan/2023_2024_photos/10.jpeg`

Эти изображения перечислены в `unavailable_images` JSON и не выводятся сломанными карточками. Публикации перенесены с исходными адресами; доступность всех сторонних СМИ отдельно не проверялась. В 2023–2024 источник говорит, что Ания Мирзегалямова и Искандер Бадиги разделили второе и третье места: индивидуальные места не выдумывались.

Каскад отключало правило `animation: none` для `.tarhan-person, .tarhan-season-card` в `assets/css/content-pages.css`. Теперь оно действует только до инициализации JS как защита от скрытого содержимого при недоступном скрипте. Общая очередь — `src/js/components/card-reveal.js`; подключения — `jury.js`, `ambassadors.js`, `archive.js`. Инициализация работает и после DOMContentLoaded, архив больше не создаёт повторные таймеры для растущей очереди. Учтено уменьшение движения.

Проверки: сборка Vite успешна (имеются предупреждения об устаревшем Sass API/import), `node tests/card-reveal.test.mjs` прошёл; `tests/verify-remaining-seasons.php` подтвердил публикацию, шесть финалистов на сезон, все локальные файлы галерей и HTTP 200. В браузере проверены классы готовности и реальные CSS-анимации на всех трёх типах карточек; новые карточки архива появляются при прокрутке. На момент проверки Local содержит 28 карточек жюри и 8 амбассадоров с изображениями — прежние сведения об их отсутствии устарели.

Воспроизводимая подготовка: Local PHP запускает `tests/prepare-remaining-seasons.php <каталог исходных HTML>`, где имена HTML — `tarhan-2022_2023.html` и аналогичные. Установка: `tests/install-remaining-seasons.php <существующая папка резервной копии>` через `tests/invoke-local-php.ps1`. Установка меняет БД и медиатеку; не запускать для обычной проверки. Повторный импорт заменяет ранее импортированные поля, поэтому перед ним сравнить ручные изменения редактора.

Резервная копия перед установкой: `.seasons-backup-20261026-131212.local/` (исходные записи и метаданные, CSS и manifest). Старые файлы сборки в Local не удалялись; manifest обновлён только для трёх страниц каскада и их зависимостей.

После запуска Local пользователем созданы и проверены уменьшенные версии всех 43 импортированных фотографий. При первоначальном импорте CLI PHP работал без GD; браузер получал оригиналы (обложки до 7671 px). Исправлено запуском `tests/resize-season-images.php` через Local PHP с расширениями mysqli, mbstring, fileinfo и gd, а также актуальным mysqli.default_port из `tests/local-runtime.ps1`. Скрипт сохраняет оригиналы, создаёт размеры WordPress и проверяет srcset. Для всех 43 изображений проверены подходящие размеры и srcset; `tests/verify-remaining-seasons.php` дополнен проверкой адаптивных изображений в HTML.
