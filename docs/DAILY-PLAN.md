## Как работаем и заканчиваем день

- Пользователь пишет только PHP/бэкенд; WordPress разбираем вместе. HTML, JavaScript и SCSS выполняет помощник.
- На день — одна основная самостоятельная задача и один заранее названный совместный шаг. Точное условие нового упражнения объясняется перед началом, с входом, выходом и примерами.
- После прохождения проверок пользовательской задачи и совместного шага день закрыт. Не добавлять внезапно новые обязательные упражнения и полировку.
- Свои законченные задачи отмечаем отдельно от готовности всего этапа. Задержка интеграции помощника или ответов заказчика не обнуляет сделанное пользователем.
- Если что-то не закончено, фиксируем один конкретный остаток и пересматриваем следующий день. Не прибавлять его молча к полному объёму завтра и не продлевать занятие автоматически до ночи.
- Перед занятием можно уменьшить объём под доступное время. Старые оценки часов не использовать как фактический остаток.
- Завершение дня подтверждается кодом/проверками, а не количеством проведённых часов. Для внешней зависимости отмечать «ожидаем ответ», а не ставить фиктивную галочку.

**Твоя основная задача:** написать `tarhan_validate_essay_file_info($filename, $size_bytes, $allowed_extensions, $max_bytes)` в своём модуле эссе. Лимиты — параметры, без выдуманных окончательных чисел.

- [ ] Извлекается расширение без точки, регистр приводится к нижнему.
- [ ] Возвращается понятная ошибка для отсутствующего/неразрешённого расширения, пустого файла и превышения размера.
- [ ] Допустимый файл и размер ровно на границе принимаются.
- [ ] Пройдены проверки обычного файла, верхнего регистра, отсутствия расширения, `work.pdf.exe`, нулевого размера, превышения и границы. Результат содержит `extension`, `size_bytes`, `error`.

**Вместе в WordPress:** разобрать один путь «запрос с эссе → вызов твоей проверки → результат», затем проверить сохранение и чтение технической работы с привязкой к участнику.

**Моя часть:** форма, JS/SCSS, обработчик, серверный допуск, фактическая проверка содержимого загрузки и непубличное хранение, подтверждение сохранения. Защищённую страницу связать с успешным тестом. Метаданные файла сами по себе не подтверждают его фактический формат.

**Точка остановки для тебя:** функция файла прошла проверки и разобран один обработчик WordPress. **Результат этапа для сайта:** обычный технический участник с допуском сдаёт текст или файл, организатор получает работу. Если интеграция или материалы не готовы — отдельно записать остаток и пересмотреть объём 20-го, не выдавать готовую функцию за готовую сдачу эссе.
