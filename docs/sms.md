# SMS участникам

Модуль: `wordpress/wp-content/plugins/tarhan-testing/tarhan-sms.php`.

События: успешное сохранение регистрации на сезон; сохранение результата теста (успех / неуспех). Уведомление получает личный телефон из анкеты соответствующего сезона. Баллы, проценты и ответы в SMS не попадают. После последней неудачной попытки текст сообщает, что попыток не осталось. Автоматическое завершение по времени создаёт SMS, когда движок теста фиксирует завершение; существующий движок обрабатывает просрочку при обращении к нему.

Настройки: **Тестирование → SMS участникам**. Реальная отправка по умолчанию выключена. Подготовлен адаптер SMS.ru; выбор заказчика ещё не подтверждён. Для запуска нужны выбранный сервис, его API-ключ, баланс и согласованный отправитель. Ключ вводится в админке (при повторном открытии не отображается) либо задаётся константой `TARHAN_SMS_API_KEY` в серверном `wp-config.php`. Пустое поле ключа сохраняет старый. Ключ не включать в Git/логи/переписку. Другой сервис требует отдельного адаптера.

Контракт адаптера проверен по https://sms.ru/api/send . POST по HTTPS; код принятия сообщения не равен подтверждению доставки. Длинные русские тексты могут тарифицироваться несколькими SMS.

Очередь `wp_tarhan_sms` создаётся через `tarhan_sms_install()` или при первом входе администратора после обновления. Уникальный ключ события исключает повторы регистрации/результата. Фоновая задача `tarhan_sms_tick` запускается WP-Cron раз в минуту; на хостинге нужен регулярный системный запуск WP-Cron для работы без посещений сайта. За один запуск до 10 сообщений. Отключённая отправка сохраняет очередь; при включении обрабатываются события только за последние сутки. Более старые помечаются устаревшими.

Статусы: очередь, отправляется, принято сервисом, ошибка, требует проверки, устарело. При таймауте/обрыве неизвестно, принял ли сервис запрос: автоматического повтора нет, иначе возможны дубли и повторная оплата. Проверить ID/статус в кабинете SMS-сервиса. В админке последние 50 записей с замаскированными телефонами; ошибки не выводят ключ/ответ сервиса целиком. Сбой SMS не откатывает регистрацию или тест.

Проверка в Local: `./tests/invoke-local-php.ps1 -Script tests/verify-sms.php`. Все HTTP-запросы перехватываются тестом, реальные SMS не отправляются. Проверяются сценарии сообщений, завершение по таймеру, отсутствие дублей, выключенный сервис, принятие, отказ, таймаут и устаревшая очередь. Данные теста откатываются транзакцией; схема очереди остаётся установленной.
