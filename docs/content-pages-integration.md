Импортированы 14 фотографий сезона и обложка; восемь амбассадоров заполнены текстом из сохранённой копии оригинала. Пять групп интеграционных проверок пройдены с откатом тестовых данных. Страницы проверены в браузере, в том числе на ширине 375 px: горизонтального переполнения и ошибок JavaScript не обнаружено. Резервная копия перед успешной установкой: `content-pages-20261024-151929`.

В «Страницы → Все страницы»:

- **Эксперты** (страница жюри, ID 12), **Амбассадоры** (ID 14): заголовок, надзаголовок, вступление, карточки людей. У каждой карточки имя, должность, описание, фотография из медиатеки. Кнопки «Выше» и «Ниже» меняют порядок. «Удалить запись» удаляет карточку из формы; изменение применяется при сохранении страницы.
- **Сезон 2021–2022**: вступление, цифры, этапы, финал, жюри сезона, финалисты, итоги, ссылки на выпуски, фотографии и публикации СМИ. Изображения хранятся в медиатеке WordPress.
- **Архив сезонов**: выводит опубликованные страницы с шаблоном «Сезон конкурса». Кнопка «Создать новый сезон» в редакторе создаёт черновик с нужными полями.
- **Участнику**, **Контакты и документы**: существующие материалы перенесены в шаблоны WordPress. Их отдельный редактор полей не входит в этот перенос.

После изменения полей нажмите **Обновить**. В новом сезоне сначала заполните материалы, затем нажмите **Опубликовать**. Сезоны 2022–2023, 2023–2024, 2024–2025 создаются черновиками: сведения других сезонов туда не копируются.

## Установка в Local

Local должен быть открыт, сайт Tarhan-wp запущен. Скрипты не запускают отдельные MySQL/PHP/nginx.

1. Собрать Vite в `.participant-build` с `--base=./ --manifest`.
2. Выполнить PHP `tests/prepare-content-pages.php`: подготовить HTML и данные сезона.
3. Выполнить `tests/deploy-local-content.ps1`: проверка доступности базы, резервная копия темы, перенос файлов, создание страниц, импорт фотографий, интеграционная проверка.

Резервные копии находятся в каталоге артефактов чата, в папках `content-pages-ДАТА-ВРЕМЯ`. `pages-before.json` хранит прежние страницы и метаполя, `page-ids.json` — созданные/найденные страницы. Существующие пользовательские метаполя не перезаписываются при повторном запуске. Страницы с другим шаблоном или заполненным обычным содержимым требуют отдельного переноса и останавливают установку.

Проверка `tests/verify-content-pages.php` работает в транзакции с откатом: сохранение и повторное чтение, порядок карточек, удаление последней карточки, права/nonce, защита от обрезанной формы, экранирование, отсутствие черновиков в архиве.
