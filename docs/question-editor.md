# Редактирование вопросов

В WordPress: **Тестирование → Вопросы теста → Добавить вопрос**.

Прямая ссылка: http://tarhan-wp.local/wp-admin/edit.php?post_type=tarhan_question

1. Название сверху нужно для поиска вопроса в админке.
2. В поле «Текст вопроса» введите текст, который увидит участник.
3. Варианты ответа запишите каждый с новой строки, без нумерации и пустых строк между ними.
4. В поле правильного ответа введите один номер, начиная с 1. Например, `2` означает вторую строку вариантов. Ниже автоматически показывается нумерация и текст выбранного правильного ответа.
5. Нажмите «Опубликовать» или «Обновить». Черновики не попадают в тест.

При ошибке прежние сохранённые данные сохраняются, а вопрос исключается из новых тестов до исправления. Уже начатая попытка использует собственный снимок вопросов: изменения банка её не меняют. Правильные ответы не передаются участнику; баллы рассчитываются на сервере.

Редактор банка также открывается кнопкой «Редактировать вопросы» на странице настроек тестирования и в редакторе страницы «Тестирование».

На 24.10.2026 в базе нет опубликованных вопросов и есть один черновик. Для старта теста нужны как минимум 50 опубликованных корректных вопросов. Демонстрационные заглушки не импортированы как настоящие вопросы.

Проверены сохранение и повторное чтение, выбор сохранённого вопроса в тест, подсчёт по введённому номеру, ошибки в номере и вариантах, права и nonce. `tests/verify-question-editor.php` откатывает тестовые записи. Дополнительно пройдены десять сценариев `tests/verify-attempts.php`, включая сохранение снимка начатой попытки и отсутствие правильных ответов в публичных данных.
