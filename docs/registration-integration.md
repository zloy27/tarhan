# Подключение регистрации

Страница registration.html сверстана. Реальной регистрации и подключения к внешнему справочнику пока нет.
Форма блокирует отправку, пока не настроены оба серверных адреса и не пройдены проверки.

## Адреса

Подготовлен клиент для ответа DaData suggestions/address:
https://dadata.ru/api/suggest/address/
Он обращается только к серверу сайта, а не напрямую в DaData.
До загрузки registration.js WordPress должен задать window.tarhanRegistration:

```js
window.tarhanRegistration = {
    addressEndpoint: '/wp-json/tarhan/v1/address',
    registerEndpoint: '/wp-json/tarhan/v1/register',
    nonce: 'значение, выданное сервером'
};
```

Это контракт будущих маршрутов, а не уже существующие маршруты.
Ключ DaData хранится только на сервере.
Адресный маршрут принимает POST JSON { query } и возвращает { suggestions: [{ value, data }] }.
Используются только результаты с data.house_fias_id.
Изменение введённого текста сбрасывает выбранный адрес.
Справочник в этой версии рассчитан на адреса РФ; для зарубежных адресов требуется отдельный источник.

## Регистрация

Маршрут принимает multipart/form-data и возвращает { success: true } только после регистрации.
Любая ошибка или отсутствие маршрута не считается успехом.
На сервере обязательно повторить проверки полей, даты, паролей, согласия, размера и фактического формата файла;
проверить идентификатор адреса по справочнику, допустимые значения конструктора учреждения,
уникальность email и защиту от повторных заявок, ограничить частоту запросов.
Nonce для гостевой регистрации сам по себе не является достаточной защитой от спама.
Пароли обрабатывает WordPress; файлы согласия должны храниться с ограничением доступа.
Не сохранять пароли и документы в логах. Клиент не сохраняет их в localStorage.

Конструктор учреждения ограничивает форму, тип и числовой номер, но не подтверждает существование учреждения.
Для этого нужна серверная сверка с реестром. Учреждения без номера оформляются через организаторов.
Для совершеннолетних файл согласия необязателен, как в исходной форме; квартира также необязательна.
