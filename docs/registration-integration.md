# Подключение регистрации

Актуальное состояние на 21 октября 2026: регистрация, вход/выход и восстановление подключены в локальном WordPress. По прямому выбору пользователя новая форма использует локальный справочник «регион → населённый пункт», а улицу и дом участник вводит вручную. Ключ DaData для этого не нужен.

Подробности регистрации/файлов/авторизации: `docs/participant-integration.md`. Актуальный адресный контракт, данные, лицензия и проверки: `docs/geography-integration.md`.

WordPress задаёт `window.tarhanRegistration`: `registerEndpoint`, `geographyEndpoint`, `token`, `nonce` (для вошедшего пользователя). Региональные данные доступны по GET `/wp-json/tarhan/v1/geography/regions`, поиск по GET `/wp-json/tarhan/v1/geography/localities?region_id=...&query=...`.

POST `/wp-json/tarhan/v1/register` принимает multipart/form-data. Адресный режим новой формы: `address_mode=directory`, `region_id`, `locality_id`, `street`, `house`, необязательная `apartment`. Сервер проверяет идентификаторы и связь регион/населённый пункт, игнорирует присланные клиентом названия. Существование улицы и дома не подтверждается. После подтверждённого создания аккаунта возвращается `{success:true,login_url:...}`. Гостевой запрос требует заголовок `X-Tarhan-Token`, связанный с HttpOnly cookie.

Старые маршруты `/address` и режим `address_fias_id` сохранены как отдельный вариант полного адреса с серверной проверкой DaData. Внешний провайдер без ключа недоступен; новая форма его не использует.

Форма учреждения ограничивает тип/номер, но не подтверждает существование школы по реестру. Для совершеннолетних файл согласия необязателен, как в исходной форме; квартира также необязательна. Пароли обрабатывает WordPress, документы согласия хранятся вне публичной папки. Проверки дат, полей, согласия, фактических файлов, дублей и частоты запросов выполняются сервером. Успех не показывается без подтверждения сервера.

Внешняя доставка писем на целевом хостинге ещё не проверена. Тема и лимиты эссе остаются независимой внешней зависимостью.
