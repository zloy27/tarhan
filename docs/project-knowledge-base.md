# База знаний проекта «Тархан»

Этот файл хранит структуру сайта, маршруты, пометки и принятые решения. Новую информацию можно добавлять прямо в соответствующие разделы.

## Основная навигация

- **Логотип**
  - ведёт на главную страницу: `index.html`
- **О конкурсе**
  - ведёт на блок главной страницы: `index.html#about`
- **Жюри**
  - ведёт на страницу: `jury.html`
- **Амбассадоры**
  - ведёт на страницу: `ambassadors.html`
- **Новости**
  - основная страница: `news.html`
  - архив сезонов: `seasons.html`
- **Контакты**
  - контакты и документы: `information.html`
  - подготовка к конкурсу: `preparing.html`
- **Войти**
  - страница входа: `login.html`
  - после входа пользователь переходит в закрытый блок страниц — структуру нужно дополнить.

## Статус страниц

### Уже существуют

- `index.html` — главная.
- `jury.html` — жюри.
- `ambassadors.html` — амбассадоры.
- `information.html` — контакты и документы.

### Нужно создать

- `news.html` — новости.
- `seasons.html` — архив сезонов.
- `preparing.html` — подготовка к конкурсу.
- `login.html` — вход.

## Закрытый блок после входа

Структура пока не определена.

Предполагаемые вопросы для уточнения:

- какая страница открывается сразу после входа;
- нужен ли личный кабинет;
- где пользователь запускает тест;
- нужна ли отдельная страница результата;
- может ли пользователь редактировать анкету;
- нужна ли история попыток.

## Пометки

- Все внутренние ссылки должны работать локально, на GitHub Pages и после переноса на домен.
- Для перехода к блоку «О конкурсе» на главной должен существовать элемент с `id="about"`.
- Перед добавлением нового маршрута нужно обновить этот файл, header и footer.
