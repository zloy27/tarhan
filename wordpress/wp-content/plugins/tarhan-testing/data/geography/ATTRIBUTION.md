# GeoNames registration directory

Data © GeoNames contributors, [GeoNames](https://www.geonames.org/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Adapted from RU country and alternate-name snapshots: Russian names selected; populated places grouped by region; search strings normalized. No streets, houses, population or coordinates are returned to the registration form. Internal population values only rank search results. This is not the official GAR/FIAS registry. The source provides no guarantee of completeness, timeliness or accuracy. See metadata.json for source URLs, hashes, date, version and counts.

## District label supplement

The separately published districts.json index and districts/*.json tables is a boundary-derived database under [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), © OpenStreetMap contributors / Wambacher via geoBoundaries. Russian name labels also credit GeoNames (CC BY 4.0). Source RUS ADM2 boundaries represent 2017 and are simplified; this supplement is for disambiguation and is not an authoritative current administrative registry. The source URL, checksum and processing method are published in districts.json. Reproduce with tests/enrich-geography-districts.py after tests/build-geography.py. All generated district labels, including adaptations, are available in the machine-readable districts/*.json files included beside this notice.
